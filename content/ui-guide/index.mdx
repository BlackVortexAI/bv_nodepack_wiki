## Image export

BV Node Pack can create deterministic PNG captures of the active graph, a
selection, or an open BV interface. See [Export Graph and BV UI Images](/ui-guide/image-export)
for supported sources, backgrounds, metadata, and the automation API.

## BV windows

BV-owned editors support workspace, floating, minimized, and switching behavior.
Window identity is scoped by workflow and concrete node identity.

Open an editor from the node that owns its data. When two workflows or two nodes
are open, the title and active owner must change with the selected window. A BV
window must never edit a similarly titled node in another graph.

## Persistence

Product data belongs in the workflow. Appearance and local window preferences
remain outside workflow JSON unless they are explicitly part of a node contract.

## Node widget appearance

BV controls mounted directly on ComfyUI nodes use the shared widget UI layer. Its
surface, border, foreground and muted colors inherit the active ComfyUI canvas
theme, including light and dark appearances. This widget bridge is separate from
the theme system used by full BV windows and dialogs.

If a node widget appears with dark controls on a light canvas or the reverse,
confirm that the current frontend bundle is loaded before changing BV window-theme
preferences. Those preferences do not override ComfyUI-owned node-widget colors.

After editing product data, save the workflow and reload it. Moving, minimizing,
or docking a window may remain a local preference and must not be used as proof
that the workflow data persisted.

## Keyboard and focus

Shortcuts act only in their documented context. Text fields and prompt editors
must retain normal typing, selection, copy, paste, and undo behavior. Before
reporting a shortcut failure, click the canvas or owning BV window and repeat the
documented combination once.

## Legacy Debug Mode

Newly inserted Regional nodes hide deprecated ports. Enable **BV Regional Legacy
Debug Mode** in ConfigUI Settings or press `Ctrl+Alt+B` to inspect them. Existing
connected legacy ports stay visible.

## Notifications

Migration summaries, unresolved resources, validation fallbacks, and legacy
wiring warnings remain visible. A warning or deployment state is not evidence of
successful execution.

Record the exact notification text and the action that produced it. Dismissed
messages may remove useful diagnosis context, so capture them before retrying or
changing the workflow.

## Recovery

If an editor appears stale, close and reopen that editor first. Then save and
reload the workflow. Use a full ComfyUI restart and browser hard refresh only
when the shipped frontend and Python runtime may be out of sync.
