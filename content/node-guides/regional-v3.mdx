## Goal

Create a two-region 1024 × 1024 workflow, optionally assign independent LoRA
resources, and execute it through one compatible conditioning or attention node.

## Prerequisites

- BV Node Pack 1.0.0 release candidate or later;
- one compatible model and matching execution node;
- optional external LoRA stack producer and tested LoRAs;
- every collector and consumer in the same concrete graph.

## Build the document

1. Add **BV Regional Prompt** and open the Regional Editor.
2. Set the document to 1024 × 1024.
3. Author Global and Background prompts.
4. Add two named regions and draw their geometry.
5. Choose `generation`, `detailer`, or `both` usage deliberately.

## Add a consumer

Connect `regional` to Native Conditioning or one compatible model-specific
Attention node. Connect the ordinary model, CLIP, conditioning, latent, and
sampler path required by that backend.

## Add scoped LoRA resources

1. Name an external stack with **BV Named LoRA Stack**.
2. Connect it to **BV LoRA Stack Collector**.
3. Open the LoRA capability editor.
4. Select the collector and resource for Global or one region.
5. Use `Replace`, `Merge`, `Subtract`, or `Clear` intentionally.

## Verify

Save, reload, reopen the editor, change a live external stack, and queue an
uncached run. Confirm unrelated scopes remain unchanged.

## Save Civitai-compatible metadata

**BV Regional Image Save** keeps its `regional` input optional. Leave it
disconnected to retain the previous save behavior and metadata path.

When connected, use the same Regional Context that produced the image and keep the
node's `document_id` aligned with that context. The PNG then contains:

- raw Civitai/A1111-style `parameters` text with the combined Global, Background
  and enabled generation-region prompts;
- sampler, scheduler, steps, CFG, seed, size and denoise values when one supported
  sampler can be resolved upstream;
- the resolved base-model name and SHA-256 hash when the model file is available;
- materialized Regional V3 LoRAs and upstream core `LoraLoader` or
  `LoraLoaderModelOnly` resources, including strengths, scopes and hashes; and
- the complete versioned context in `bv_regional`, alongside ComfyUI's `prompt`
  and `workflow` chunks.

Metadata enrichment is fail-soft for file resolution and hashing: an unavailable
resource hash does not block image saving. A mismatched Regional Context and
`document_id` is rejected because silently attaching another document would make
the provenance misleading.

> Spatial conditioning guides a model. It does not guarantee anatomy,
> separation, interaction, or prompt compliance. Freeze a visually accepted
> seed per published workflow.
