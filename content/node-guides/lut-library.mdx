## Goal

Choose built-in or downloaded LUTs, register several named workflow resources,
and deliberately test Stable or Experimental catalog candidates.

## Load and register LUTs

1. Add **BV LUT Loader** for a standalone manual chain, or add **BV LUT Registry**
   when several named resources belong to one workflow.
2. Choose one of the built-in looks or a `.cube` file discovered below
   `ComfyUI/models/luts`.
3. Use **BV Apply LUT** for a direct application, or resolve the resource through
   a Regional LUT plan and loop.

For the direct example on this page, connect `Load Image.image` to
`BV Apply LUT.image`, connect `BV LUT Loader.lut` to `BV Apply LUT.lut`, and send
the resulting image to **Preview Image**. It uses `Built-in: HDR Color Boost` at
strength `1.00`. With `mask` disconnected, the LUT applies globally.

BV Node Pack 1.3.0 includes twelve
deterministic built-ins: Identity, Warm Contrast, Cool Graphite, Digital Green,
Machine Blue, Dustfire, Steel Action, Sunbleached Coast, Expired Film, Classic
Monochrome, Grayscale, and HDR Color Boost. This is a documentation-target
statement, not a claim that 1.3.0 has already been released.

A built-in changes color only. In particular, HDR Color Boost is the name of a
creative color transform; it does not create HDR luminance or metadata, grain,
bloom, or local contrast.

The embedded example workflow references the BV test-character image shown in
the screenshot. After importing the PNG into ComfyUI, select your own file in
**Load Image** if that source image is not available locally.

## Download catalog channels

- **Stable** contains curated direct-download candidates. Pinned catalog
  metadata and checksums protect identity and transfer integrity, but do not
  replace license or input-profile review.
- **Experimental** contains candidates that are not yet fully validated and may
  change or be removed. A listed LUT may have an unsuitable input profile or
  produce an undesirable result.
- The selected channel is persisted separately from workflow JSON.
- `Download more LUTs…` in a LUT selector opens **BV Download Manager**; the
  Registry editor also provides **Download LUTs**.
- At startup, a valid working copy wins when its `catalog_version` is equal to
  or newer than the bundled catalog. Online refresh remains asynchronous, so an
  unavailable remote source does not block ComfyUI startup.
- Manual Refresh checks the selected channel. A remote catalog replaces the
  effective catalog only when its version is strictly newer.
- Installed resources publish into open selectors automatically. If an already
  open selector remains stale, focus the graph and press `R`.

Downloaded files are written below `ComfyUI/models/luts/downloaded`. Catalog
metadata records the pinned source revision, checksum, expected profile and
license. GPL entries retain their GPL obligations; camera-profile LUTs must not
be treated as generic display-space looks.
