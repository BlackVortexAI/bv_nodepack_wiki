## Ecosystem

BV Node Pack is built for the ComfyUI ecosystem and integrates with its graph, execution, persistence, and frontend extension contracts.

Some documented recipes optionally use third-party projects such as Impact Pack for detector and SEGS workflows. Those dependencies retain their own licenses, compatibility boundaries, and support channels.

Workflow-image exports used during documentation production may be created with **ComfyUI Workflow Image Export**. The export tool is documentation tooling; it is not a runtime dependency of BV Node Pack.

## Attribution review

Final publication requires a license and attribution review against the exact dependency versions used by approved example workflows. Until that review is complete, this page remains under review and avoids implying endorsement by third-party maintainers.
