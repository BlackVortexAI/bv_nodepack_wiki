This page contains the complete version history recoverable from the repository's
own changelogs and version commits. Versions 0.0.7 through 0.0.1 are visibly separated

contemporary changelog.

## 1.2.1 — 2026-08-30

- Added **BV Inspect Any**, a bounded in-node preview for arbitrary values with
  copy support and an ordinary `STRING` output for downstream logging or routing.
- Made BV widget surfaces inherit the active ComfyUI light or dark canvas theme
  through the shared widget UI layer.
- Added an optional `regional` input to **BV Regional Image Save**. Connected
  workflows embed Civitai-compatible combined prompts, sampling values, model and
  LoRA names, resolved hashes, scope data and the complete BV Regional context.
- Preserved the previous save behavior when `regional` is disconnected, so existing
  workflows do not opt into the additional metadata implicitly.

Source: repository commit `0a3e83c`. The Anima E2E check used two generation
regions, the Anima base model and the Anima Turbo LoRA, then verified the raw
`parameters`, `bv_regional`, `prompt` and `workflow` PNG chunks.

## 1.2.0 — 2026-08-29

- Added the workflow-local **BV LoRA Registry**, catalog library and Full/Quick
  selection flows while retaining the published V2 registry chain.
- Completed the asynchronous LUT catalog with separate Stable and Experimental
  channels, offline working-copy fallback, manual refresh and checksum-verified
  downloads.
- Added nine deterministic built-in looks: Digital Green, Machine Blue, Dustfire,
  Steel Action, Sunbleached Coast, Expired Film, Classic Monochrome, Grayscale and
  HDR Color Boost.
- Expanded the Experimental LUT channel to 46 profile- and license-documented
  candidates without changing the tested Stable channel.
- Normalized newly discovered LUT paths across Windows and browser-facing choices
  so Registry and Loader selections remain interoperable.

The built-in looks were manually tested and the Experimental catalog was confirmed
to load on 29 August 2026. This does not claim visual qualification of every look
or successful download of every external LUT.

## 1.1.0 — 2026-08-28

- Added Regional LUT authoring and execution workflows, including registry, plan,
  loop, catalog, download and prototype tooling.
- Unified Classic, Nodes 2.0 and Node Library presentation for technical, provider
  and legacy ports, including connection-aware Legacy Debug visibility.
- Stabilized node sizing and widget projection across mode changes, Subgraphs and
  hot reloads without overwriting user-resized dimensions.
- Refreshed Regional graph-dependent selectors and sender targets when relevant
  nodes, editors or regions were created, replaced or removed.
- Normalized Control Center, Seed, prompt-debug and text-preview presentation and
  added regression coverage for the shared UI rules.

Source: repository commit `3b07b2b`. This entry records the committed source
version and does not independently claim a tag, registry publication or release.

### 2026-08-20 — v0.13.0
