## Install with ComfyUI Manager

1. Search for **BV-NodePack**.
2. Install or update the package.
3. Restart ComfyUI completely.
4. Hard-refresh the browser so the Python nodes and shipped JavaScript bundle match.

## Install with Git

From the `ComfyUI/custom_nodes` directory, run:

```bash
git clone https://github.com/BlackVortexAI/bv_nodepack.git
```

Restart ComfyUI completely, then hard-refresh the browser.

## Verify discovery

Confirm that both `BV Regional Prompt` and `BV Seed` appear in the node
library. If either node is missing, inspect the complete ComfyUI startup log
for BV import errors before changing the installation. A browser refresh
cannot repair a failed Python import.
