> This guide targets **BV Node Pack 1.3.0**. As of 13 September 2026 the Comfy
> Registry lists 1.4.3 and 1.4.2 as active after a manual review; the history is in
> [issue #217](https://github.com/Comfy-Org/registry-backend/issues/217) (closed).
> A newly published version is scanned first and may be flagged until it is
> reviewed, so ComfyUI Manager can offer an older version for a while; check the
> installed version after updating. Publication does not imply Registry approval.
> The pack's security model is documented on the
> [Security and Registry Evidence](/reference/security-and-registry-evidence) page.

## Install with ComfyUI Manager

1. Search for **BV-NodePack**.
2. Install or update the package.
3. Restart ComfyUI completely.
4. Hard-refresh the browser so the Python nodes and shipped JavaScript bundle match.

## Install with Git

From the `ComfyUI/custom_nodes` directory, run:

```bash
git clone https://github.com/BlackVortexAI/bv_nodepack.git
```

Restart ComfyUI completely, then hard-refresh the browser.

## Verify discovery

Confirm that both `BV Regional Prompt` and `BV Seed` appear in the node
library. If either node is missing, inspect the complete ComfyUI startup log
for BV import errors before changing the installation. A browser refresh
cannot repair a failed Python import.
