## Build a deterministic first graph

1. Add **BV Seed** and choose a fixed value for this workflow.
2. Add **BV Empty Latent Random Ratio**.
3. Select `1024`, enable only `1:1`, and use the alignment required by the model.
4. Connect the latent to the sampler path required by the selected model.
5. Save, reload, and confirm the same dimensions and effective seed.

The documentation does not enforce one global seed. Every published workflow
freezes its own visually accepted seed. Comparisons must keep model, seed,
sampler, scheduler, resolution, prompts, and all unrelated parameters unchanged.
